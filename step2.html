SAU KHI TẢI XONG

Cài đặt 3uTools

Làm lần lượt theo các bước bên dưới để hoàn tất cài đặt.

01

Mở file vừa tải

Mở file cài đặt 3uTools vừa tải về máy. Nếu Windows hiện thông báo hỏi có cho phép ứng dụng thực hiện thay đổi trên thiết bị hay không, chọn Yes.

02

Cài đặt 3uTools

Tick vào I agree EULA and Privacy Policy, sau đó bấm Install.

03

Mở 3uTools

Khi màn hình hiển thị Install succeeded, quá trình cài đặt đã hoàn tất. Bấm Launch để mở 3uTools.

04

Cài Apple Driver

Khi 3uTools yêu cầu cài thành phần cần thiết, chọn Install Driver.

!

Chờ quá trình cài Driver hoàn tất trước khi thực hiện bước tiếp theo.

05

Hoàn tất ✓

Khi 3uTools mở được giao diện như bên dưới, bạn đã cài đặt 3uTools thành công.
